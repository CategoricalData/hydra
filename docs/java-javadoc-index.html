Hydra Java API

JavaDoc reference for the published Hydra Java packages.

Each package below is documented separately. See also the Hydra home page and the Maven Central artifacts (groupId net.fortytwo.hydra.java).

Packages

hydra-build

The translingual home of Hydra's build system, promoted into Hydra itself.

hydra-go

The Go coder: sources describing how Hydra is generated into Go.

hydra-haskell

The Haskell coder: sources describing how Hydra is generated into Haskell.

hydra-java

The Java coder: generation of Java source from Hydra schemas and terms.

hydra-jvm

Shared JVM utilities used across Hydra's JVM-targeting coders (Java, Scala).

hydra-kernel

The Hydra kernel: core types and terms, the type system, coders, and the DSL runtime.

hydra-lisp

The Lisp coder: sources for the shared Clojure/Common Lisp/Emacs Lisp/Scheme output.

hydra-pg

Property graphs: the PG model plus TinkerPop/Gremlin, Cypher, and GQL integrations.

hydra-python

The Python coder: sources describing how Hydra is generated into Python.

hydra-rdf

RDF and SHACL support: the RDF syntax model and mappings to and from Hydra.

hydra-scala

The Scala coder: sources describing how Hydra is generated into Scala.

hydra-typescript

The TypeScript coder: sources describing how Hydra is generated into TypeScript.
